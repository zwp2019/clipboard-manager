# 本地 Paste 风格体验

当前版本保留 WinUI 3、SQLite 与本地文件存储，不增加云存储或同步。

## 界面

- 底部悬浮面板高 300 DIP，按显示器 DPI 换算；内容预览/编辑时临时扩展高度。
- 单行导航：搜索、剪贴板、收藏、带色点的收藏板、添加、更多菜单。
- 208 × 208 DIP 卡片，46 DIP 彩色类型栏；类型与时间在左，来源应用图标在右。
- 浅色卡片使用白色正文区；深色卡片使用独立深色正文区。主题画刷只定义在主题字典，避免全局资源覆盖主题。
- 文本和富文本共用黄色类型栏，链接蓝色，图片红色，代码紫色，文件绿色。
- 字符数、链接地址或图片尺寸作为底部辅助信息；主要操作通过右键、快捷键或右上角更多菜单访问。
- 鼠标滚轮可横向浏览卡片，接近末尾继续加载历史；底部提供手动加载入口。

## 图片

卡片从本地文件流异步解码缩略图，避免未打包 WinUI 的文件 URI 加载失败。缺失或损坏的缩略图会从原图重建；旧的小缩略图会在需要时升级，原图不改动。原图已删除时显示明确占位信息，不再呈现无提示空白卡片。

来源图标同样通过流解码并进入有上限的 LRU 缓存。来源程序不存在时显示类型图标，不联网下载图标。

图片详情中的“提取图片文字”使用 Windows OCR，不上传图片。可选已安装的识别语言与 2 倍小字增强；自动模式在系统模型识别出纯英文时、且英文模型可用时复核。长图和宽图使用带重叠的原分辨率分块，按文字框位置去重并恢复阅读顺序，不再把整张长图压缩到引擎尺寸上限。透明像素先合成到白色底。关闭预览会取消识别，空结果不清除旧的识别内容。当前为手动提取并索引，不自动扫描全部历史。

预览与编辑只有弹窗外层滚动，正文自动展开；图片详情不再套内层 ScrollViewer，避免滚轮被内层文本框或预览区截住。底部操作栏固定，内容区可滚到最后。

本机运行检查仅检测到 `zh-Hans-CN` OCR 模型。6000 像素长图的末尾标记在普通和增强模式均能提取，但英文仍出现拆词与形近字错误；应安装英文 OCR 语言组件后再评估英文准确率。语言选择器列出实际可用模型，并提示英文模型缺失；系统语言组件未被自动安装。分块和放大不等于更换 OCR 模型，不保证所有图片的准确率都会提高。

## 数据与边界

HTML 剪贴板按 UTF-8 与字节偏移解析，RTF 保留原始 8 位数据，不再将富文本误读为 UTF-16。复制旧版本已误解码的 HTML 时尝试反向恢复，无法恢复则用完整纯文本生成兼容内容，不修改历史库。卡片上的 Enter、Ctrl+C 和双击均收起面板并将内容复制到系统剪贴板；搜索框 Enter 会立即完成搜索，复制选中的结果并收起面板。由用户返回目标输入框按 Ctrl+V 粘贴，程序不自动激活目标窗口、不模拟粘贴按键。右键“仅复制”只写入系统剪贴板，成功时显示 3 秒提示；搜索及详情文本框中的 Ctrl+C 保持原生文本复制行为。

收起时卡片内容在 180 毫秒内淡出并轻微下移，完成后隐藏窗口。系统关闭动画时直接隐藏。复制后在当前显示器的工作区底部显示两行浮动卡片：上方“已复制”与 Ctrl+V 小键帽，下方为内容摘要；左侧按文字、链接、图片、代码、文件显示彩色类型图标和成功角标。卡片为 352 × 76 DIP，20 DIP 圆角、半透明渐变表面、细描边和柔和阴影，跟随应用浅色/深色主题，并适配高对比度与 DPI。约 2 秒后淡出；图片显示名称，文件显示文件名及数量。提示不抢焦点、不拦截鼠标，连续操作会替换上一条提示。系统剪贴板写入失败时显示警告图标与“复制失败”，不显示粘贴键帽。系统关闭动画时提示直接显隐。

- 数据库 V3 将已有分组导入独立收藏板；空板可以持久保存。
- 删除收藏板会把其条目退回历史，不删除条目本身。
- 收藏及收藏板内容不参与自动过期/数量清理；主动删除和“清空历史”仍会删除内容。
- 从历史复制不会再次入库：写入内容携带当前会话的内部操作标记，不依赖 Windows 通知何时到达；详情文本框内的原生复制按实际剪贴板所有者识别。此规则不受“保留重复”设置影响，该设置仅针对外部复制。
- 队列由选中历史手动组成，仅保存在当前会话，复制成功后移出；当前不接管系统 Ctrl+V，也不自动收集后续复制。
- 链接显示本地已捕获的信息；不联网抓取网页封面或标题。
- 当前没有 AI 推荐、MCP 接口和图片旋转功能。

## 构建与回测

背景 Acrylic 在创建控制器前调用 `DispatcherQueue.EnsureSystemDispatcherQueue()`，补齐系统合成所需队列；WinUI 的调度队列本身不能替代它。主面板使用原生 `DesktopAcrylicKind.Thin` 的浅色/深色预设，不覆盖 TintColor、TintOpacity、LuminosityOpacity 或 FallbackColor，也不叠加额外底色，避免背景与前景主题不匹配。初始化成功、系统高级效果开关、原生主题参数及失败原因写入本地日志，失败时使用实色回退。卡片正文仍为不透明底色。该效果的实际呈现需在用户桌面回测，不能由编译结果确认。

界面按 Paste 参考图恢复为轻磨砂面板、实色卡片和完整彩色顶栏。浅色正文底为不透明白色，深色正文底为不透明深灰，正文不透出桌面；移除动态反光、渐变卡片与内部玻璃胶囊。搜索和收藏板导航居中，卡头为 44 DIP，来源图标直接融入卡头，不加白色底座。卡片正文为 12.5 DIP、时间与页脚为 10 DIP，长正文底部淡出；卡片使用低透明度的真实合成投影，不使用额外描边模拟阴影。主面板保持 296 DIP 高，卡片为 208 × 208 DIP、14 DIP 圆角，键盘焦点与选中提示贴合卡片。收藏板、编辑与预览保留独立模态窗口，避免改变面板尺寸；菜单与设置页使用稳定的高不透明度背景。

本轮重点回测：新建收藏板时面板是否保持高度；Tab/方向键切换卡片时是否仍有方形黑框；右键菜单及弹窗在浅色、深色和高 DPI 下是否清晰；弹窗保存、取消、Esc 后是否恢复正常操作。

WinUI 构建使用 Visual Studio 的 MSBuild，纯业务层测试使用 `dotnet test`。

```powershell
msbuild ClipboardManager.sln /restore /p:Configuration=Release
dotnet test tests/ClipboardManager.Tests -c Release
```

发布构建位于 `src/ClipboardManager.App/bin/Release/net10.0-windows10.0.19041.0/win-x64/`。启动新版本前先从托盘退出旧版本，单实例锁会阻止两个正常版本同时运行。

本次界面调整只做编译、静态检查和自动化业务测试，桌面交互和视觉效果由用户回测。建议关注浅色/深色切换、不同 DPI、旧图片缩略图恢复、右键菜单、中文搜索及复制与收起面板。
