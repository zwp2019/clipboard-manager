# 2026-08-19

## 剪贴板项目（Windows Clipboard Manager）首次实现

按 `AI_DEVELOPMENT_SPEC.md` 从零搭建了完整的 Windows 剪贴板管理软件（C#/.NET 10/WinUI 3）。

- 用户选择：方案 B（macOS 上写全部代码，拷贝到 Windows 编译运行）+ 尽可能多做（Phase 0-15）。
- 本机限制：macOS 26 ARM64，无 .NET SDK，WinUI 3 无法在本机编译验证；包版本如还原失败需在 Windows 上更新。

### 架构（7 个项目）
- `src/ClipboardManager.Domain`：ClipboardItem/Tag/Favorite/AppSettings/ClipboardType（纯模型）
- `src/ClipboardManager.Contracts`：DTO + 端口接口（IClipboardMonitor/Reader/Writer/Repository/...）
- `src/ClipboardManager.Application`：ClipboardPipelineService、ClipboardStorageService、SearchService、HistoryService、QuickPasteService、SettingsService、HistoryCleanupService、ClipboardHashService、ClipboardNormalizer、ClipboardDeduplicationService、TimerDebouncer
- `src/ClipboardManager.Data`：SQLite+WAL+Dapper+FTS5、MigrationRunner、ChineseTokenizer（中文 bigram）、ClipboardItemRepository、SettingsRepository、DatabaseBackupService（VACUUM INTO）
- `src/ClipboardManager.Infrastructure`（net10.0-windows）：Win32 P/Invoke 集中 NativeMethods、CoreHostWindow（message-only window 承载剪贴板/热键/托盘）、ClipboardMonitor（AddClipboardFormatListener 事件监听）、ClipboardReader（含锁定重试+DIB 解码）、ClipboardWriter、InternalClipboardGuard（防死循环）、GlobalHotkeyService+HotkeyParser、TrayIconService（GDI+ 画图标）、ImageStorageService（缩略图）、AutoStartService（注册表）
- `src/ClipboardManager.App`（WinUI 3，win-x64 自包含未打包）：App.xaml.cs（DI+单实例+托盘热键接线）、MainWindow（无边框+Mica+多显示器定位+键盘操作）、SettingsWindow、LauncherViewModel（300ms 防抖+取消旧搜索）、SettingsViewModel、ClipboardItemViewModel（懒加载缩略图）、ThemeService、LruImageCache
- `tests/ClipboardManager.Tests`：xUnit 单测（Hash/分词/归一化/去重）+ 集成测试（仓储 CRUD/FTS5 中英文搜索）+ 性能测试（10k，Trait Category=Performance）

### 关键技术决策
- FTS5 external content 表 + 中文 unigram+bigram 空格分词；<3 字符短查询自动降级 LIKE
- 图片存文件系统（Images/Thumbnails 按 yyyyMM），LRU 缓存 256 张缩略图
- 去重=同 hash 2 秒窗口内忽略 + 库里同 hash Touch 时间戳移到最前
- 历史清理：保留天数 + 最大条数 Trim（后台每小时）
- 隐私：排除应用列表（来源进程名匹配），日志不记内容
